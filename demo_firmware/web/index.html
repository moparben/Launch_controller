📋 Message Reference

System Messages (0x100-0x1FF)

0x100
Heartbeat - Node status ping
Data[0]: Node ID, Data[1]: Status

Launch Control (0x200-0x2FF)

0x200
Launch Command - Initiate launch sequence
Data[0]: Countdown time (seconds)
0x201
Abort Command - Emergency abort
Data[0]: Abort reason code
0x202
Arm Command - Arm launch system
Data[0]: Safety key status
0x203
Disarm Command - Disarm launch system
No data payload

Tracking & Camera (0x300-0x4FF)

0x300
Track Target - Camera tracking command
Data[0-1]: X position, Data[2-3]: Y position
0x301
Telemetry Data - Rocket position/velocity
Data[0-3]: Position, Data[4-7]: Velocity

Cluster Engines (0x600-0x6FF)

0x602
Cluster Ignite - Fire specific engine
Data[0]: Engine ID, Data[1]: Fire command, Data[2]: Duration
